** tmux
focus-events is a tmux option that makes tmux forward terminal focus gain/loss escape sequences (\e[I / \e[O) to the programs running inside it.

  Claude Code (and other TUI apps like Neovim) use these to detect when you switch away from or back to the terminal window. Without it enabled, apps inside tmux
  never learn the window lost focus, so features like "pause animations when unfocused", "check for external file changes on refocus", or "stop polling when
  backgrounded" don't work.

  Enable it in ~/.tmux.conf:

  set -g focus-events on

  Then reload tmux (tmux source ~/.tmux.conf).
